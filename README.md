# SA Azadipour – GitHub Pages Website

## Dateien
- `index.html` – komplette Website
- `style.css` – Design und Animationen
- `script.js` – Menü, Scroll-Effekte und Animationen
- `assets/Logo.png` – dein vorhandenes Logo

## Wichtig
Lege deine vorhandene Datei **Logo.png** in:
`assets/Logo.png`

Die Website verwendet für die großen Hintergrundbilder externe Unsplash-Bilder. Dadurch musst du keine großen Bilddateien in GitHub speichern.

## GitHub Pages
Lade alle Dateien in dein Repository hoch und aktiviere GitHub Pages über:
Settings → Pages → Deploy from a branch → main → / (root)

Danach kannst du eine eigene Domain wie `saazadipour.com` verbinden.
